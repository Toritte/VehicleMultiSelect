# Release notes

## v0.12
- Adds optional Bingus Shared Loader integration while retaining standalone startup.
- Adds a discoverable vehicle module and delegation to the recognized installed v16 loader.
- Confirmed vehicle selection and spawning without Bingus, and with Bingus v17, HD2 HUD+ and Vanilla Plus Megapack.
- Keeps independent Exosuit, FRV and Tank options in standard and noimages packages.
- Does not bundle Bingus Shared Loader.

## v0.11

Moves startup from boot to the Wwise callback resource. User-confirmed working together with HD2 HUD+ 0.1.12. Standard and noimages packages retain three independent vehicle options and identical game files. Bingus Shared Loader is not required and must not be combined with this Wwise replacement.


## v0.1 — release preparation
- Standalone vehicle multi-selection for Steam build 25480438.
- Independent Exosuit, FRV and Tank options in the manager.
- No Bingus Shared Loader dependency.
- Four-slot and unlock requirements preserved.
- Representative thumbnail and category-specific artwork supplied by Toritte.
- Build information and file hashes included in VehicleMultiSelect-manifest.json.
