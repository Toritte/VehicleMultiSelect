# Vehicle MultiSelect
![Vehicle MultiSelect](assets/banner.png)

By [Toritte](https://github.com/Toritte). Select different exosuits, FRVs and tanks together in Helldivers 2's standard four stratagem slots.

**No Bingus Shared Loader required.** Enable Exosuit, FRV and Tank independently in the mod manager, or combine them. The four-slot limit and vehicle unlock requirements remain unchanged. This mod does not allow duplicate copies of the same stratagem.

## Installation
1. Close the game and remove earlier Vehicle MultiSelect packages. Disable separate Exosuit MultiSelect and FRV MultiSelect mods.
2. Import the installable Vehicle MultiSelect ZIP into **Helldivers 2 Mod Manager**.
3. Open **EDIT**, check the vehicle categories you want, enable the mod and **Deploy**.
4. Start the game and select your vehicles. Restart the game after changing options.

To uninstall, close the game, remove or disable this mod, redeploy and restart. Details: [INSTALL.txt](INSTALL.txt).

## Options
| Option | Included vehicle records |
| --- | --- |
| Exosuit | Four exosuit variants |
| FRV | Three FRV variants |
| Tank | Bastion and STORM |

Only vehicles available to your account can be selected. You still have four stratagem slots in total.

## Compatibility
Supports Steam build **25480438**. Game updates may require a mod update. Do not combine this mod with other boot-script replacements or other MultiSelect mods. The shared loader is not required; compatibility with unrelated mods must be assessed separately.

The author confirmed the standalone options package and the artwork package working in-game on September 24–25, 2026, including exosuit/FRV selection and spawning. Every option combination and two distinct tanks together have not been individually confirmed.
