Vehicle MultiSelect v0.12 — Toritte
Allows Multiple Selection of Any Vehicles.


Installation : 
1.  Close the game.
2.  Import the installable ZIP into Arsenal or HD2MM.
2-1. If you have installed Bingus Shared Loader made by CowboyBingus, YOU MUST PLACE THIS MOD ABOVE THE LOADER, OTHERWISE IT WOULD NOT WORK.
3.  Check options you'd like among Exosuit, FRV and/or Tank, enable the mod, then Deploy.
4.  Start the game.
    If you wish to change any options, please do close the game beforehand.

Uninstallation :
Close the game, You must fully close the game to uninstall the mod.
Disable this mod, purge OR deploy again then relaunch the game.

Four slots and unlock requirements remain unchanged. Selecting the same
stratagem multiple times is not supported for this mod this time.


Supported game version: Steam build 25480438 / Game version 7.1.1
Game updates may require a mod update.


TROUBLESHOOTING
Log: %LOCALAPPDATA%/VehicleMultiSelectStandalone.log
The applied line lists the detected options. If an old option remains active,
remove earlier packages and clean stale deployed patches through the manager
before deploying your desired mod list again.

PACKAGE CONTENTS
Addon/Exosuit, Addon/FRV, Addon/Tank: game patch files.
manifest.json: manager configuration.
VehicleMultiSelect-manifest.json: build hashes and verification scope.
thumbnail.png and Images/: representative and option artwork.
